# Ofentse's Sweet Grace Patisserie 🍰❤️

An interactive birthday cheesecake experience for Ofentse's 26th birthday.

## Features

- Pink patisserie kitchen with a photographic kitchen background.
- Five-tap biscuit crushing interaction.
- Drag-and-drop ingredient and topping stages.
- Magic poof transitions with sparkles.
- Fridge cooling countdown.
- PNG lighter states for unlit and lit candles.
- Confetti birthday finale.
- Personal birthday card with Ofentse's photo and a Numbers 6:24-26 blessing.
- Native drag-and-drop support for laptops and touch dragging for phones.

## Run Locally

This is a static HTML project. Open `index.html` in a browser, or serve the folder with any static file server.

For example, with Python installed:

```text
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Mobile Use

On laptops, draggable items use regular drag-and-drop. On phones, touch and hold an ingredient or topping, move it over the kitchen scene, and release it to drop it.

The page uses the CDN version of `canvas-confetti`, so the confetti effect requires an internet connection unless that library is downloaded and hosted locally.
